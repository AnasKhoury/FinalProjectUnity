# Teachable Machine Files

Put the exported Teachable Machine TensorFlow Lite files here:

- `model.tflite`
- `labels.txt`

The labels must match the `recognitionLabel` values on `XR Origin > MuseumRealObjectRecognitionController`:

- `Ship`
- `Rock`
- `Big Vase`
- `Small Vase`

The active app flow is real-object recognition only. Marker tracking is not used by the generated scene.
